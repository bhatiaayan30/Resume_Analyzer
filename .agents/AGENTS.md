# Custom Rules

- Never use the term "AI" or any website/service/product names (e.g., ChatGPT, Gemini, Razorpay, Chrome, etc.) in Git commit messages. Keep commit messages generic and focused on technical functionality.
- Whenever a Git commit is made, save a copy of all active artifacts (e.g., `walkthrough.md`, `implementation_plan.md`, `task.md`) in the artifacts directory, named using the format `[filename]_[commit_hash]_[sanitized_commit_message].md`.
